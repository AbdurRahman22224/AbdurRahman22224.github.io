## Overview

Developed a custom deep learning model using the Keras Functional API, combining CNN and LSTM layers for multi-modal data processing with over 3 crore parameters.

## Key Features

- **Data Pipeline:** Implemented a robust data pipeline with a custom generator handling 2 lakh+ images for efficient training, and preprocessing numeric and text-based features alongside image data.
- **Optimization:** Implemented feature extraction using a pre-trained architecture, applying transfer learning and freezing layers to improve model efficiency.
