## Overview

Made a Retrieval-Augmented Generation (RAG) chatbot using LangChain, Ollama, ChromaDB, and Chainlit.

## Key Features

- **Local Inference:** Used the Ollama server to run Llama3 locally for low-latency inference.
- **Context Awareness:** Improved the chatbot’s understanding by retrieving relevant context using ChromaDB.
- **User Interface:** Designed a user-friendly chatbot interface with Chainlit for smooth, real-time interaction and engagement.
