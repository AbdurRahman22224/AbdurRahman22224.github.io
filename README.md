# Abdur Rahman - Portfolio

Welcome to my personal portfolio website! This project showcases my research in Machine Learning, Deep Learning, and NLP, along with my academic publications and technical blogs.

## 🚀 Tech Stack

- **Framework:** [Astro](https://astro.build)
- **Styling:** [Tailwind CSS](https://tailwindcss.com)
- **UI Components:** [React](https://reactjs.org) & [Framer Motion](https://www.framer.com/motion/)
- **Deployment:** GitHub Pages

## 🛠️ Local Development

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/AbdurRahman22224/portfolio.git
    cd portfolio
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```

## 📦 Deployment

This site is configured to deploy automatically to **GitHub Pages** via GitHub Actions.
- The workflow file is located at `.github/workflows/deploy.yml`.
- Pushing to the `main` branch triggers a new build and deployment.
